% 从 agent task 引入到 LLM
Large language model (LLM)-powered agents have become increasingly prevalent, with agent tasks typically involving multiple LLM requests and incurring high end-to-end latency dominated by LLM inference. 
% 阐述核心动机：Agent 的 LLM 瓶颈随负载变化而变化
Our profiling shows that the latency bottleneck shifts with serving load, from decoding at low concurrency to queueing at high concurrency.

% 引入 SD 说明 SD 和 Dynamic SD 的问题
Speculative decoding (SD) is a state-of-the-art technique for accelerating LLM inference, but its benefit decreases with serving load and may even degrade performance under high load, while existing dynamic SD methods may still incur overhead when SD is disabled because they do not fully switch to native Non-SD execution.
% 提出我们的方法
To address these challenges, we design SpecSys, an efficient inference system for agent workloads. 
% 开放 SD 切换接口
SpecSys exposes an externally controllable runtime interface that enables complete iteration-level switching between native SD and Non-SD execution modes.
% 预测 agent task 剩余 step 数
SpecSys further employs a lightweight history-based estimator to predict the remaining steps of each agent task based on its workflow, workload, current step, and prompt-derived keywords.
% 基于负载调度任务和切换 SD
Based on the online serving load, SpecSys selectively enables SD under low load to alleviate the decoding bottleneck, while prioritizing tasks with fewer predicted remaining steps under high load to reduce queueing delay. 
% 介绍实验
We conduct extensive evaluations across three LLMs, four agent tasks, three agent workflows, and two hardware platforms. Compared with strong baselines, including ThunderAgent, vLLM Dynamic SD and SGLang Adaptive SD, SpecSys reduces average job completion time (JCT), achieving 1.18$\times$--2.10$\times$ speedups.
